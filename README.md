## ✨ What is this?

Fontaine pulls **anime, movies, TV shows, and live sports** into one clean app — then adds a community, an economy, a shop, comments, stats, and a watch list on top. Because why not.

> Built for fun. Shared for fun. Enjoy it. 🍿

---

## 🧩 Features

- 🎥 **Stream everything** — anime, movies, TV, sports
- 🎨 **Modern UI** — clean and smooth
- 👥 **Community** — profiles & comments
- 💰 **Economy + Shop** — earn coins, spend coins
- 📊 **Stats & Tracking** — your watch history, visualized
- 📌 **Watch List** — save it, watch it later
- 📱 **Android APK** — *coming soon*
